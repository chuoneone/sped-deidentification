# Data Model: 新類別與規則

## 類別（`CATEGORIES` 新增，依序接在既有類別後）

| 類別 | 部分保留（標準） | 範例輸出 |
|---|---|---|
| 國際電話 | 國碼（含後面的分隔）；北美格式為區碼 | `+44 [國際電話]`、`(415) [國際電話]` |
| 信用卡 | 末 4 碼 | `[信用卡]4242` |
| SSN | 全部隱藏 | `[SSN]` |
| IBAN | 國別碼 | `GB[IBAN]` |
| IP | IPv4 前兩段／IPv6 前兩組 | `192.168.[IP]` |
| 生日 | 年份 | `1985-[生日]`、`March 14, [生日]`… 年份在後時為 `[生日], 1985` |

每個類別有一組標記顏色（`--mark-<類別>`）。

## 內建規則（`BUILTIN_PATTERNS` 新增）

| id | 名稱 | 類別 | 檢核 |
|---|---|---|---|
| intl-phone | 國際電話（含國碼／北美格式） | 國際電話 | 號碼有效性、排除 +886、過長時修剪 |
| credit-card | 信用卡號 | 信用卡 | Luhn、發卡號段、分組格式 |
| us-ssn | 美國社會安全碼 | SSN | 號碼段 |
| iban | IBAN 國際銀行帳號 | IBAN | mod-97、國別長度、過長時修剪 |
| ipv4 | IPv4 位址 | IP | —（範圍寫在規則中） |
| ipv6 | IPv6 位址 | IP | 網址解析器 |
| dob | 出生日期（依標籤） | 生日 | 月 1–12、日 1–31 |

`tw-landline` 的規則擴充 +886 寫法。

## `Pattern.validate`（擴充）

`(match, before) => boolean | number`：`true` 接受整段，`false` 拒絕，數字表示只接受開頭這麼多字元（其後繼續比對）。
