# Quickstart: 驗證版面還原、勾選框與傾斜辨識

```bash
npm install
npm run examples          # 重產掃描範例、角度樣本與原稿（需本機 Chrome）
npm test
npm run build && npm run preview
npm run eval:ocr -- --verbose   # 另開終端機
```

1. **表格線條與底色**：載入掃描範例。第 2 頁表單的格線、表頭灰底，第 3 頁名冊的橫線與表頭底色，第 4 頁 Invoice 的表格線，在預覽與下載的 PDF 中都出現在原位置。
2. **文字顏色**：第 2 頁的藍筆手寫、第 5 頁名片的彩色公司名，在預覽與輸出中維持顏色。
3. **勾選框**：第 2 頁所有方框出現在原位置，「新申辦」「男」「同戶籍地址」「電子郵件」為已勾選；文字中沒有「口」「[」「了」之類的雜字；名冊中的「湖口鄉」仍是文字。
4. **傾斜與轉向**：評分報表的角度樣本中，3°／6° 的字元召回率與 0° 相差 ≤ 3 個百分點，90°／180° 達 0° 的 95% 以上。
5. **無點陣殘留**：輸出 PDF 除了保留的圖片外，沒有其他影像。
6. **回歸**：主範例的字元召回 ≥ 98.8%、印刷值 ≥ 138/144，總時間增加 ≤ 30%。
