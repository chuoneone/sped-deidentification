# Research: 掃描辨識補強、名片排版不重疊與「不需還原」的標記方式

量測沿用 `npm run eval:ocr`（真實瀏覽器流程），並以 `scratchpad` 內的除錯腳本逐一重讀失敗區域。005 完成時的基準：

- 第 1 頁字元召回 96.7%、手寫值 1/2；
- 名片頁字元召回 98.5%、預覽中有 3 組文字互相重疊，另有多處上下行相貼；
- 主範例總計：字元 98.8%、印刷值 138/144、21.7 秒。

## R1 漏字區域放大重讀

- **Decision**: 漏字補辨識（`uncoveredText` 找到的區域）先以原尺寸讀；若沒有任何字達到可信門檻（60），再放大 2 倍讀一次。
- **Rationale**: 「董事長」這類字距加寬的大字，放大後才讀得出來；多數漏字區域原尺寸就讀得到，只有失敗時才多花一次。

## R2 行首重讀（條列編號）

- **Decision**: 每一行若在行首左側 2.5 倍字高內有未被可信字詞（信心 ≥ 30）覆蓋的墨跡，就把「墨跡＋該行前兩個字」一起以單行模式重讀。重讀結果中位於原本行首左側、信心 ≥ 60 的字詞補到行首；與它們重疊的低信心舊字詞（「人」「大」）移除。若原尺寸讀不出，再放大 2 倍讀一次。
- **Rationale**: 「一」單獨看只是一橫，有上下文才認得出來；這也涵蓋「(1)」「A.」等任何條列符號。
- **Alternatives**: 放寬漏字補辨識的尺寸門檻，會把雜點、印章、表格殘線都送去重讀，誤判與時間都增加。

## R3 中文句中的短英文片段

- **Decision**: 夾在中文行中、1～3 個字母、信心 < 90 的英文字詞（TR），一律以純中文模型重讀（原尺寸與放大 2 倍），讀成中文且平均信心高於原讀法時取代。
- **Rationale**: 中文行中孤立的短英文多半是中文字（尤其手寫）被誤讀。真正的英文縮寫（TEL、ID）讀成中文的信心通常更低，不會被取代。

## R4 極低信心的中文字

- **Decision**: 信心 < 30 的單一中文字（闊:0），以純中文模型重讀，讀成單一中文字且信心較高時取代；每頁最多 20 個。
- **Rationale**: 信心接近 0 代表原讀法幾乎是猜的；門檻定低，避免把大量正常字送去重讀而拖慢速度。「則」（主旨的「旨」，信心 80）不在範圍內。

## R5 字級估計與行距限制（名片重疊）

- **量測**：中文字框高度約為實際字級的 0.95 倍；目前字級取 Tesseract 的行高，約為實際字級的 1.24 倍（第 1 頁內文實際 11.25pt，估成 13.9pt）。字普遍畫大了約兩成，行距密的名片因此上下相疊。
- **Decision**:
  1. 一段文字含 2 個以上單字中文時，字級 = 中文字框高度中位數 ÷ 0.95（不超過原本的估計）；
  2. 同一頁上下相鄰、水平範圍重疊的兩段文字，字級合計不超過兩者基線距離（上段字的下緣不低於下段字的上緣），超過時兩者等比縮小。
- **Rationale**: 第 1 點讓字級接近原稿；第 2 點處理英文行（字框高度與字級比例不固定）與傾斜名片造成的基線估計誤差，保證不重疊。

## R6 標記方式（Marker style）

- **Decision**: 輸出標記由兩個獨立設定決定：
  - 輸出方式（既有）：決定保留哪些字元（前段＋隱藏部分＋後段）。
  - 標記方式（新增）：決定隱藏部分如何呈現。
    - 編碼：`[類別:編碼]`，附編碼表，可還原（預設）；
    - 類別：`[類別]`；
    - 空白佔位：隱藏部分的每個文字或數字以「○」取代，其他字元保留。
- 不需還原時：
  - 不產生編碼表，`applyRedactions` 回傳空的對照；
  - 下載、打包、複製只處理文件；
  - 「已下載」只看文件；
  - 編碼範圍（共用、匯入）的設定保留在狀態中但不顯示，切回「編碼」即恢復。
- **Rationale**: 「保留多少字」與「要不要還原」是兩件事；分開設定，現有使用者的流程（預設編碼）完全不變。
- **Alternatives**: 把「類別」「空白」併入輸出方式成五選一，選項會混雜兩種概念，且「部分保留＋空白」無法表達。

## R7 憲章原則 II（可逆）

- **Decision**: 修訂憲章 1.0.0 → 1.1.0。原則 II 改為：預設輸出必須可還原；使用者在介面上明確選擇「不需還原」的標記方式時，可輸出不含編碼的文件，介面必須清楚標示無法還原，且不產生編碼表。
- **Rationale**: 使用者回報的真實需求（只要去識別化）；原則的目的是避免使用者在不知情下失去還原能力，明確選擇與清楚告知即可滿足。

## 實作中的修正（依量測）

- **漏字區域放大重讀**：只用於「完全沒有任何辨識字詞」的區域（董事長）。原本對所有讀不清的區域都放大，結果「游文瑜」（第一次被讀成英文「WESC」）被放大後的不完整讀法「文瑜」取代；保留給後面的英文第二意見處理，才會讀回「游文瑜」。
- **行首重讀**：
  - 墨跡的右緣必須在行首前一個字高以內（條列編號緊貼行首）；名冊中前一欄的低信心字詞因此不會被誤當成行首。
  - 上下文要約 5 個字（只讀到第 2 個字時「二」讀不出）。
  - 補回的字只要不是大半落在既有字上就採用（「二」的字框連同「、」一起框進去）。
- **低信心中文字重讀**：
  - 門檻 < 10，且新讀法要高出 15；
  - 只接受單一漢字（避免把「游」換成中文標點後被當雜訊濾掉，或把「婷」（20）改成「生」）。
- **字級**：中文字框高度 ÷ 0.95；上下兩段字形重疊時先縮小下段，仍不夠才兩段等比縮小。
