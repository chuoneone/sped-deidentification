# Quickstart: 驗證掃描辨識補強、名片排版與標記方式

```bash
npm install
npm test
npm run build && npm run preview
npm run eval:ocr -- --verbose   # 另開終端機
```

1. **第 1 頁信函**：評分報表第 1 頁的「少讀的字」不再包含「函」「一」「二」「三」「四」「六」「董」「事」「長」「丁」「承」；手寫值 2/2；字元召回 ≥ 98.5%。
2. **名片頁**：評分報表名片頁的「重疊」為 0；在網站載入掃描範例，捲到第 5 頁，相鄰兩行文字不相疊。
3. **標記方式**：載入「委外服務契約書.docx」範例 →「調整輸出方式」→ 標記方式選「類別」：預覽顯示 `[姓名]`，下載按鈕變成「下載去識別化文件」，只下載一個檔案，內容沒有任何 `[類別:xxxxxx]`；改選「空白佔位」：`王小明` 在「部分保留」下顯示為 `王○○`，手機 `0912-345-678` 為 `0912-○○○-○○○`；改回「編碼」：下載又附編碼表。
4. **多檔**：同時載入兩個檔案、選「類別」→ 打包下載：壓縮檔內沒有 `.mapping.csv`。
5. **還原頁**：上傳以「類別」輸出的文件，看到「找不到編碼標記」的提示。
6. **回歸**：主範例字元召回 ≥ 98.8%、印刷值 ≥ 138/144、線段 66/66、底色 18/18、勾選框 10/10；總時間 ≤ 25 秒。
