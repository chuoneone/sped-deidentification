# Contract: 輸出設定面板與下載（標記方式）

## 輸出設定面板

- 「輸出方式」（部分保留／全部隱藏／自訂）不變。
- 新增「標記方式」三選一，每個選項附範例與說明：
  - 編碼 `[姓名:6e679d]`：可還原，附編碼表；
  - 類別 `[姓名]`：不需還原；
  - 空白佔位 `○○○`：不需還原，會保留原本的字數。
- 選「類別」或「空白佔位」時，顯示提醒「不需還原：下載只有去識別化文件，沒有編碼表，日後無法還原」；「編碼範圍」區塊（整批共用、匯入既有編碼表）不顯示。
- 收合時的摘要：輸出方式膠囊＋標記方式膠囊＋依兩者組合的範例（例：`A123456789 → A1○○○○○○○○`），不需還原時加註「無法還原」。

## 工具列

| | 編碼 | 類別／空白佔位 |
|---|---|---|
| 主按鈕（單檔） | 下載（文件＋編碼表） | 下載去識別化文件 |
| 主按鈕（多檔） | 打包下載全部（N 個檔案） | 同左（壓縮檔內只有文件與清單） |
| 更多選單 | 只下載去識別化文件、只下載編碼表、（文字檔）複製、（共用時）下載合併編碼表 | （多檔）下載此檔、（文字檔）複製；沒有項目時不顯示選單 |
| 狀態列 | 編碼表是還原的唯一憑證，請妥善保管。輸出方式：… | 標記方式：類別（不需還原），下載只有去識別化文件，無法還原。輸出方式：… |

## 還原頁

- 上傳的文件中找不到任何編碼時，提示：「這份文件裡找不到編碼標記；若輸出時選了『類別』或『空白佔位』，就無法還原。」

## 評分屬性（評分工具讀取）

- 預覽中每個 `.pdf-item` 的 `style.left`／`style.top`／`style.fontSize`（以 pt 換算）與 `data-w`：評分工具據此計算同頁文字段的重疊數。
