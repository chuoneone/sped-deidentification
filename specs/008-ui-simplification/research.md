# Research: 介面精簡

## R1 現況量測（實作前記錄）

以「委外服務契約書.docx」範例、1280×900 視窗量測：

- **去識別化頁**：輸出設定展開後的高度、可見元素數；
- **偵測規則頁**：表格寬度是否超過容器（橫向捲動）、正規表達式是否可見。

數字在實作開始時記錄於本檔「量測紀錄」。

## R2 去識別化頁的輸出設定

- **Decision**:
  - 「保留」「標記」各一列，以分段按鈕（radio 外觀改成相連的按鈕）呈現；
  - 每列右側一行範例或說明：保留列顯示 `A123456789 → …`，標記列顯示「可還原，附編碼表」或「不需還原」；
  - 提醒合併為一個 `notice`，內容依組合串接；
  - 類別表與編碼範圍各自放進 `<details>`：
    - 「依類別調整（N 類）」：選「自訂」時預設展開；
    - 「進階：編碼範圍」：標記方式為「編碼」時才出現。
- **Rationale**: 保留原生 radio 與 details，鍵盤操作與無障礙維持不變，不新增元件。

## R3 狀態列

- **Decision**: 狀態列只留一行：
  - 「部分保留・編碼（可還原）」，以及有啟用的「共用編碼」「沿用匯入」；
  - 「ⓘ 格式限制」；
  - 「⚠ 含部分保留（N 類）」小標籤，類別清單與說明放在提示框；
  - 「編碼表是還原的唯一憑證」移到下載鈕的提示框。

## R4 偵測規則頁

- **Decision**:
  - 內建規則加上 `group`（tw／intl），自訂規則自成一組；
  - 每組一個 `<details open>`，標題含規則數與整組開關（checkbox，部分啟用時 `indeterminate`）；
  - 每條規則一列（grid 排版，不用寬表格）：開關、名稱、類別徽章、範例、「查看規則」；
  - 「查看規則」展開同列下方的細節：完整比對規則（可換行）、檢核方式、預設保留方式、來源，自訂規則另有編輯與刪除；
  - 新增表單由頁首的「＋ 新增自訂規則」或「編輯」打開，表單有「取消」。
- **Rationale**: 15 條規則以分組加單行呈現，可以一次看完；比對規則仍可檢視，符合憲章原則 IV。

## R5 檢核方式說明

- 內建規則的檢核方式（身分證檢核碼、統編檢核碼、Luhn、mod-97、號碼有效性……）目前只寫在名稱的括號中。
- 改為 `note` 欄位，在「查看規則」中顯示；名稱縮短，例如「國際電話」「信用卡號」。

委外服務契約書範例，輸出設定展開、預設選項（部分保留・編碼）：

| 項目 | 改版前 | 改版後 |

| 工具列高度（1280／390） | 98／301px | 98／244px |
| 規則頁高度（1280） | 1381px | 782px |

| 預設畫面可見的正規表達式 | 15 條 | 0 條 |
| 新增表單預設顯示 | 是 | 否（按「＋ 新增自訂規則」才打開） |
