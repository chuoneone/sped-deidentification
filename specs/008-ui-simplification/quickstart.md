# Quickstart: 驗證介面精簡

```bash
npm test
npm run build && npm run preview
```

1. 載入「委外服務契約書.docx」範例，展開「調整輸出方式」：只看到「保留」「標記」兩列與一行提醒；「依類別調整」「進階：編碼範圍」收合。
2. 選「自訂」：「依類別調整」自動展開；標記改「類別」：「進階：編碼範圍」消失。
3. 工具列狀態列只有一行。
4. 「偵測規則」頁：三個分組、每列一行、看不到正規表達式；點「查看規則」可看到完整規則；按整組開關可整組停用；按「＋ 新增自訂規則」才出現表單。
5. 手機寬度（390px）下兩頁都不需橫向捲動。
