# Feature Specification: 介面精簡（去識別化頁的輸出設定、偵測規則頁）

**Feature Branch**: `008-ui-simplification`

**Created**: 2026-10-16

**Status**: Draft

**Input**: User description: "介面精簡：選項變多後「去識別化」與「偵測規則」兩頁要更容易使用。去識別化頁：輸出設定改為「保留（部分保留／全部隱藏／自訂）」與「標記（編碼／類別／空白佔位）」兩列分段選擇，旁邊即時顯示範例；警示合併成一行；類別表收進「依類別調整」、編碼範圍收進「進階」（只在編碼時出現）；工具列狀態列精簡。偵測規則頁：依「台灣格式／國際與通用格式／自訂規則」分組，可整組啟停；每列只顯示開關、名稱、類別、範例，正規表達式與保留方式收在「查看規則」；新增自訂規則改為按鈕展開；更新截圖與 README。"

006 加入標記方式、007 加入 6 個國際類別與 7 條規則後，兩個頁面的選項明顯變多。去識別化頁的輸出設定展開後有：

- 6 張選項卡片、兩段警示；
- 一張類別表；
- 編碼範圍設定。

偵測規則頁則是 15 列、含長串正規表達式的寬表格，新增規則的表單常駐在頁尾。本規格在不減少任何功能的前提下，把常用的放前面、少用的收起來。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一眼看懂並調整輸出設定 (Priority: P1)

使用者在去識別化頁展開輸出設定，只看到兩列簡短的選擇：「保留多少」與「標記方式」，旁邊立刻顯示選擇後的樣子；需要逐類別調整或處理編碼範圍時，再展開對應區塊。

**Why this priority**: 這是每次去識別化都會經過的地方，目前一展開就佔滿整個畫面。

**Independent Test**: 展開輸出設定，預設畫面只有兩列選擇與一行提醒；切換任一選項，範例與預覽立即更新；類別表與編碼範圍預設收合。

**Acceptance Scenarios**:

1. **Given** 已載入文件，**When** 展開輸出設定，**Then** 看到「保留：部分保留／全部隱藏／自訂」與「標記：編碼／類別／空白佔位」兩列，每列旁有依目前組合的範例或說明。
2. **Given** 選了部分保留或不需還原的標記方式，**When** 檢視提醒，**Then** 相關提醒合併為一行。
3. **Given** 輸出設定展開，**When** 檢視，**Then** 「依類別調整」與「進階：編碼範圍」預設收合；選「自訂」時「依類別調整」自動展開；標記方式不是「編碼」時不顯示「進階：編碼範圍」。
4. **Given** 工具列，**When** 檢視狀態列，**Then** 只顯示目前的保留與標記方式（以及是否可還原）、格式限制說明，與一個「含部分保留欄位」的簡短提示，詳細內容放在提示框中。

---

### User Story 2 - 偵測規則一目了然 (Priority: P1)

使用者打開偵測規則頁，看到依「台灣格式」「國際與通用格式」「自訂規則」分組的規則清單，每條只有開關、名稱、類別與範例；想看比對細節時點「查看規則」；想新增規則時按「新增自訂規則」才出現表單。

**Why this priority**: 規則從 8 條增加到 15 條，現在的寬表格難以瀏覽，正規表達式的長字串造成視覺雜訊。

**Independent Test**: 規則頁不需橫向捲動就能看完所有欄位；正規表達式預設不顯示、點「查看規則」可完整檢視；新增規則表單預設不出現。

**Acceptance Scenarios**:

1. **Given** 規則頁，**When** 檢視，**Then** 規則分為「台灣格式」「國際與通用格式」「自訂規則」三組，每組標題顯示規則數。
2. **Given** 任一組，**When** 按整組的開關，**Then** 該組所有規則一起啟用或停用；組內只有部分啟用時，整組開關顯示為部分狀態。
3. **Given** 任一規則，**When** 點「查看規則」，**Then** 顯示完整的比對規則、檢核方式說明與預設保留方式；再點一次收合。
4. **Given** 規則頁，**When** 按「新增自訂規則」，**Then** 才出現新增表單（含填入範例、複製 AI 提示詞），可以取消收合；編輯自訂規則時表單同樣展開。

### Edge Cases

- **沒有自訂規則**：「自訂規則」組顯示「尚無自訂規則」與新增按鈕。
- **規則停用**：該列以淡色顯示，與現在相同。
- **窄螢幕**：兩頁在手機寬度下不需橫向捲動即可操作主要選項。
- **重新整理或切換頁籤**：分組的展開狀態不需記憶，每次以預設狀態呈現。
- **既有設定**：規則的啟停狀態與「設為預設」的保留方式沿用既有儲存，不需遷移。

## Requirements *(mandatory)*

### Functional Requirements

**去識別化頁**

- **FR-001**: 輸出設定展開後 MUST 以兩列分段選擇呈現「保留」與「標記」，每列旁顯示依目前組合產生的範例或說明。
- **FR-002**: 部分保留與不需還原的提醒 MUST 合併為一行，只在相關選項生效時出現。
- **FR-003**: 類別表 MUST 收在「依類別調整」中，預設收合；選「自訂」時自動展開。
- **FR-004**: 編碼範圍（整批共用、匯入編碼表）MUST 收在「進階」中，預設收合，且只在標記方式為「編碼」時出現。
- **FR-005**: 工具列狀態列 MUST 精簡為：目前的保留與標記方式、是否可還原、格式限制、含部分保留欄位的簡短提示；較長的說明放在滑鼠停留的提示中。
- **FR-006**: 預覽區上方的說明 MUST 縮短為一行。

**偵測規則頁**

- **FR-007**: 規則 MUST 依「台灣格式」「國際與通用格式」「自訂規則」分組顯示，每組標題含規則數，可展開收合。
- **FR-008**: 每組 MUST 提供整組啟用／停用的開關，部分啟用時呈現部分狀態。
- **FR-009**: 每列 MUST 只顯示開關、名稱、類別與範例；比對規則、檢核方式、預設保留方式與來源 MUST 收在「查看規則」中，仍可完整檢視。
- **FR-010**: 新增自訂規則的表單 MUST 預設隱藏，按「新增自訂規則」或「編輯」時才出現，可取消收合；表單功能（填入範例、複製 AI 提示詞、即時測試）維持不變。
- **FR-011**: 頁首說明 MUST 精簡為一至兩行。

**共通**

- **FR-012**: 所有既有功能與設定（啟停、保留方式、設為預設、自訂規則、編碼範圍、標記方式）MUST 維持可用，行為不變。
- **FR-013**: README 與網站的截圖、操作說明 MUST 依新介面更新。

### Key Entities

- **規則分組**：台灣格式（台灣特有格式的規則）、國際與通用格式（電子郵件與國際格式）、自訂規則（使用者新增）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 輸出設定展開後的預設畫面高度比現在減少一半以上（以相同視窗、相同範例檔量測）。
- **SC-002**: 偵測規則頁在 1280px 寬的視窗中不需橫向捲動；預設畫面中看不到任何正規表達式。
- **SC-003**: 切換保留或標記方式最多 1 次點擊；整組啟停最多 1 次點擊。
- **SC-004**: 既有自動化測試全部通過（介面相關測試依新結構更新），所有既有功能維持可用。
- **SC-005**: 在 390px 寬的手機視窗中，兩頁的主要選項都能在不橫向捲動的情況下操作。

## Assumptions

- 不新增或移除任何功能，只調整呈現方式與預設的展開狀態。
- 分組的展開狀態不寫入瀏覽器儲存（憲章只允許儲存規則設定），每次以預設狀態呈現：台灣格式與國際與通用格式展開、自訂規則有規則時展開。
- 「國際與通用格式」包含電子郵件，因為電子郵件不限國家。
- 規則透明原則（可檢視比對規則）由「查看規則」滿足：規則仍可在介面上完整檢視，只是預設收合。
