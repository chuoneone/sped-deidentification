# Contract: 辨識畫面

## 出現條件

只有在 PDF 判定為圖片型、開始辨識時才出現。一般讀檔仍使用原本的「讀取檔案中…」畫面。

## 內容

```
┌──────────────────────────────────────────────┐
│ ┌──────┐  正在辨識圖片文字                     │
│ │ 縮圖 │  掃描文件.pdf                         │
│ │ ═══ │  第 2 / 5 頁・38%                      │
│ │(掃描線)│ [██████░░░░░░░░░░]                  │
│ └──────┘  辨識第 2 頁文字…                     │
│                                              │
│ 這是圖片型 PDF，需在瀏覽器內辨識文字。首次使用會從本站 │
│ 下載約 9 MB 辨識模型；文件只在本機處理，不會上傳。   │
│                                    [取消辨識] │
└──────────────────────────────────────────────┘
```

| 元素 | 規則 |
|---|---|
| 標題 | 固定為「正在辨識圖片文字」 |
| 檔名 | 目前辨識的檔名，過長時以省略號截斷 |
| 頁數／百分比 | `engine` 階段顯示「準備中」；`recognize` 階段顯示「第 N / M 頁・P%」 |
| 進度條 | `role="progressbar"`，`aria-valuenow` 為 0–100 |
| 階段文字 | `engine`：「準備辨識引擎（首次需下載模型）…」；`recognize`：「辨識第 N 頁文字…」 |
| 縮圖 | 目前頁縮圖，上方有掃描線動畫；第一頁縮圖產生前顯示空白紙張樣式；`prefers-reduced-motion` 時停用動畫 |
| 說明 | 首次下載約 9 MB、文件不會上傳 |
| 取消辨識 | 點擊後立即關閉畫面、終止辨識，提示「已取消辨識「檔名」」 |

## 行為

- 以 `role="dialog"`、`aria-modal="true"` 呈現，取消按鈕取得焦點；底下的頁面處於 inert，無法操作。
- 多檔上傳時每個圖片型 PDF 各自出現一次畫面，檔名與頁數隨之更新。
- 375px 寬度下，縮圖改到文字上方，不產生水平捲動。
