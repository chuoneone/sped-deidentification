學生資料去識別化工具

純前端、資料不出電腦的學生資料去識別化工具。上傳 PDF、Word、Excel、TXT、Markdown 或貼上文字，自動偵測姓名、身分證字號、手機、市話、地址、電子郵件、公司名稱、統一編號與自訂識別碼；預覽、人工覆核後下載去識別化文件與 CSV 編碼表，之後可完整還原。

關於學生資料去識別化工具

學生資料去識別化工具是一個免費、開源、純前端的線上工具，用來把 PDF、Word、Excel、TXT、Markdown 文件或貼上的文字中的個人資料（姓名、身分證字號、手機、市話、地址、電子郵件、公司名稱、統一編號、自訂識別碼）自動偵測並以唯一編碼取代，同時產出 CSV 編碼表，日後可憑編碼表完整還原。所有處理都在瀏覽器內完成，檔案不會上傳到任何伺服器，離線也能使用。

本版本針對學校與特教文件調整：新增「學校與特教文件」偵測規則（欄位後的姓名、名字簡稱連動、學校、班級、學號、醫院／早療機構、障礙類別／診斷／用藥）；中文姓名不再從內文猜測（容易把「過程」「一張」誤判成人名），改由「學生姓名：」「家長：」「出席人員：」等欄位取得名單，再遮蔽全文相同的姓名與單寫的名字；名單外的名字在預覽圈選一次，全文相同的字一起遮蔽。改自 Dean Lin 的開源專案「文件去識別化工具」（MIT 授權）。

適用情境

  • 交給 AI 之前：把合約、會議紀錄、客服對話交給 ChatGPT、Claude、Gemini 摘要或翻譯前，先把姓名、電話、身分證換掉；AI 仍讀得懂 [姓名]、[手機] 的語意。
  • 委外與跨部門：客戶清單、報價單交給外包廠商或其他部門處理，回來後用編碼表還原。
  • 研究與統計：部分保留身分證前 2 碼、地址縣市區、Email 網域，在 Excel 分組統計而不暴露個人。
  • 紙本與掃描檔：申請表、名冊、名片等掃描 PDF 先在瀏覽器內辨識文字，再遮罩個資，表格框線與勾選框照原樣重繪。
  • 公開範例與教學：以「○」佔位，像公文一樣遮蔽個資後公開。

使用方式

  1. 在「去識別化」頁籤拖入檔案或貼上文字，按「開始去識別化」。
  2. 在依原格式排版的預覽中檢視自動偵測結果：預覽就是下載後的樣子，編碼以類別名稱表示（如 王[姓名]、A1[身分證]），滑鼠停留可看原文與實際輸出標記。
  3. 人工覆核：點擊標記取消誤判、在「輸出設定」的「依類別調整」整類取消、圈選文字新增漏抓的項目。
  4. 用預覽上方「輸出設定」的「保留」決定要露出多少：部分保留（預設，例如 A1[身分證]，只露出適合統計的字元）、全部隱藏，或自訂（逐類別保留前後幾碼、Email 網域、縣市區等，方便統計，可設為預設）；不需要還原時，「標記」可改選類別 [姓名] 或空白佔位「○○○」。
  5. 按「下載（文件＋編碼表）」一次取得去識別化文件（與上傳相同格式，檔名加 .deid）與 CSV 編碼表；多個檔案可一鍵打包成 ZIP，也可選擇整批共用編碼或匯入上次的編碼表沿用編碼。
  6. 需要復原時，到「還原」頁籤上傳去識別化文件與編碼表，即可下載還原檔。

常見問題

什麼是文件去識別化？

文件去識別化是把文件中可以直接或間接辨識特定個人的資訊（例如姓名、身分證字號、手機、地址、電子郵件），以遮罩或編碼取代，讓文件在交給第三方、AI 服務或研究單位時不會洩漏個資。本工具會把每筆敏感資訊換成唯一的隨機編碼，並產出 CSV 編碼表供日後還原。

我的檔案會被上傳到伺服器嗎？

不會。文件解析、個資偵測、遮罩與輸出全部在你的瀏覽器內以 JavaScript 完成，沒有任何後端；載入頁面後即使離線也能使用。瀏覽器只會儲存你的偵測規則設定，文件內容與編碼表都不會落地。

支援哪些檔案格式？

支援 PDF（含掃描檔，會在瀏覽器內以 OCR 辨識文字）、Word（.docx）、Excel（.xlsx）、TXT、Markdown，也可以直接貼上文字。單檔上限 100 MB，一次最多 10 個檔案混合處理。不支援舊版 .doc、.xls。

可以偵測哪些個人資料？

內建二十種類別。學校與特教文件：欄位後的姓名（學生、家長、導師、出席人員等，含全文相同姓名與單寫的名字）、學校、班級、學號、醫院／早療機構、障礙類別／診斷／用藥；台灣格式：中文姓名（從內文猜測，預設關閉）、身分證字號（含檢核碼驗證）、手機、市話、地址、電子郵件、公司／組織名稱、統一編號（含檢核碼驗證）與自訂識別碼；國際格式：國際電話（驗證號碼有效性）、信用卡號（Luhn 檢核）、美國社會安全碼（SSN）、IBAN 國際銀行帳號、IP 位址與出生日期（依「出生日期」「Date of Birth」等標籤判斷）。也可以用正規表達式新增自訂規則；英文姓名與地址目前需在預覽中圈選新增。

去識別化、假名化、匿名化有什麼不同？

去識別化是泛稱，指處理後無法直接識別特定個人。假名化（pseudonymization）是以代號取代可識別的資料、另外保存對照表，必要時可以還原，本工具預設的「編碼」加上 CSV 編碼表就屬於這一類；匿名化（anonymization）則是處理到無法再回推個人、也無法還原。選「類別」或「空白佔位」不會產生編碼表，但是否達到匿名化，還要看保留的字元與文件中的其他資訊，交付前請自行判斷。

把文件交給 ChatGPT 等 AI 之前，要怎麼移除個資？

把文件拖進本工具或直接貼上文字，確認姓名、身分證、手機、地址、Email 等都已標記，再下載或複製去識別化後的內容交給 AI。AI 看到的是 [姓名]、[手機] 這類標記，仍能理解語意；整個過程在瀏覽器內完成，原始檔案不會上傳。預設的「編碼」會讓 AI 的回覆保留 [姓名:6e679d] 這類標記，之後可以用編碼表還原成真實資料；不需要還原時，把「標記方式」改為「類別」即可。

掃描的 PDF 或紙本掃描檔可以去識別化嗎？

可以。沒有文字層的 PDF 會在瀏覽器內以 OCR（繁體中文＋英文）辨識，再自動偵測與遮罩；表格框線、底色、勾選框與文字顏色依原位置重繪，傾斜或放反的頁面會先自動轉正。以內附的 5 頁掃描範例實測，字元召回率約 99%。辨識仍可能有誤，下載前請逐頁核對。

可以一次處理多個檔案嗎？

可以。一次最多 10 個檔案，PDF、Word、Excel、TXT、Markdown 可以混合，每個檔案各自預覽與覆核，最後一鍵打包成 ZIP 下載；也可以讓整批檔案共用編碼，同一個人在不同檔案中是同一個編碼。

去識別化後可以還原嗎？

可以。每筆敏感資訊都換成 [類別:編碼] 形式的唯一標記，對應關係存在 CSV 編碼表中。在「還原」頁籤上傳去識別化文件與編碼表，即可取得原格式的還原檔。編碼表是還原的唯一憑證，請妥善保管。

不需要還原，可以只遮蔽、不要編碼嗎？

可以。在「輸出設定」的「標記」改選「類別」，輸出寫成 [姓名]、[手機]；或選「空白佔位」，像公文一樣以「○」取代每個字（分隔符號保留，例如 0912-○○○-○○○）。這兩種方式只下載去識別化文件、不產生編碼表，日後無法還原；「空白佔位」會保留原本的字數，需要更高的匿名性請選「類別」。預設的「編碼」仍可還原。

去識別化後的資料還能拿來統計嗎？

可以。預覽上方「輸出設定」的「保留」預設為「部分保留」，只露出適合統計的字元，例如身分證前 2 碼（地區與性別）、Email 網域、地址的縣市區，輸出如 A1[身分證:a3f9c2]；改選「自訂」可以逐類別調整，在 Excel 用 LEFT／RIGHT 就能分組統計，仍可用編碼表完整還原。多個檔案可以選擇整批共用編碼，或匯入上次的編碼表沿用舊編碼，讓同一個人在不同檔案中是同一個編碼。保留的字元越多越容易辨識出個人，請視接收對象斟酌。

輸出的文件會保留原本的格式嗎？

Word 與 Excel 直接改寫文字節點，樣式、表格、頁首頁尾與工作表結構都保留；PDF 依原始座標重建文字版面並內嵌中文字型，但圖片、圖形與原字型不會保留。

PDF 為什麼不是用黑框蓋住敏感文字？

用色塊覆蓋的 PDF，底層文字仍然可以被複製或擷取出來。本工具改以文字重建的方式輸出 PDF，敏感文字會真正從檔案中移除，不會殘留在輸出檔內。

自動偵測會不會有誤判或漏抓？

會。姓名與地址無法靠規則做到零誤判、零漏抓，所以自動偵測只是建議。本版本預設不從內文猜測姓名，只遮蔽欄位裡的姓名及其在全文的出現處，誤判少很多；名單外的名字在預覽圈選一次，全文相同的字會一起遮蔽。預覽畫面也可以點擊標記取消誤判、在「依類別調整」整類取消，確認後再下載。

這個工具要收費嗎？可以自行架設嗎？

完全免費，並以 MIT 授權開源。執行 npm run build 產出的 dist/ 是純靜態網站，可以放到 GitHub Pages、內網檔案伺服器或任何靜態空間自行架設，也可以直接以檔案方式開啟。

In English

Student Data De-identification Tool is a free, open-source, browser-only tool for redacting personal data in Taiwanese school documents such as IEPs, case meeting minutes and counselling records, adapted from Dean Lin's Data De-identification Tool (MIT). It detects names, national ID numbers, mobile and landline numbers, addresses, email addresses, company names and tax IDs in PDF (including scanned PDFs, read with in-browser OCR), Word, Excel, TXT and Markdown files, lets you review every match, and exports the redacted file in its original format. Each value becomes a reversible code with a CSV mapping table, or a plain category label or ○ placeholders when no restoring is needed. Files never leave your browser.
